# ETF 한눈에 보기

국내·해외 ETF를 검색하면 현재가, 등락률, 순자산총액(AUM), 총보수, 카테고리 등 핵심 정보를 한 화면에서 볼 수 있는 대시보드입니다. 검색한 ETF는 저장해두고 다시 볼 수 있습니다.

```
etf-dashboard/
├── app.py            # Flask 백엔드 (검색/시세 조회 API)
├── requirements.txt
├── Procfile           # 배포용 실행 명령 (gunicorn)
├── render.yaml         # Render 원클릭 배포 설정
└── index.html           # 프론트엔드 (검색창 + 정보 카드 + 저장 목록 + 검색 이력)
```

저장 목록과 검색 이력은 서버가 아니라 **브라우저의 localStorage**에 보관됩니다. 서버가 재시작되거나(무료 플랜은 15분 유휴 후 잠듦) 재배포돼도 사라지지 않지만, 대신 같은 브라우저에서만 보이고 다른 기기·브라우저와는 공유되지 않습니다.

## 로컬 실행

```bash
pip install -r requirements.txt
python app.py
```

브라우저에서 `http://127.0.0.1:5057` 접속.

## 인터넷에 배포하기 (Render, 무료)

1. 이 폴더를 GitHub 저장소에 push합니다.
2. [Render](https://render.com)에 가입 후 **New + → Blueprint**를 선택하고 방금 push한 저장소를 연결합니다. `render.yaml`을 자동으로 읽어서 설정됩니다.
   - Blueprint 없이 수동으로 만들 경우: **New + → Web Service** → 저장소 선택 → Build Command `pip install -r requirements.txt`, Start Command `gunicorn app:app`.
3. 배포가 끝나면 `https://<서비스명>.onrender.com` 같은 고정 주소가 생기고, 인터넷 어디서든 접속할 수 있습니다.

**무료 플랜의 제약사항**
- 15분간 요청이 없으면 서버가 잠들고, 다음 접속 시 첫 응답까지 몇 십 초 걸릴 수 있습니다(콜드 스타트). 저장 목록·검색 이력은 브라우저에 보관되므로 이 콜드 스타트와 무관하게 유지됩니다.

## 사용법

- 검색창에 종목명, 국내 6자리 코드(예: `069500`), 해외 티커(예: `SPY`, `QQQ`)를 입력합니다.
- 검색 결과가 여러 개면 목록에서 선택하고, 하나면 바로 정보 카드가 뜹니다.
- 정보 카드의 "☆ 저장" 버튼을 누르면 하단 "저장한 ETF" 목록에 추가되어 브라우저에 보관됩니다.
- 저장한 카드를 클릭하면 최신 시세로 다시 조회합니다.

## 데이터 소스 및 제약사항

- 시세·기본 정보는 Yahoo Finance의 공개 엔드포인트(비공식)를 사용합니다. 별도 API 키가 필요 없지만, 공식 API가 아니므로 응답 형식이 예고 없이 바뀔 수 있습니다.
- **순자산총액(AUM)·총보수·카테고리·운용사·배당수익률·설정일**은 Yahoo가 펀드 프로필 데이터를 제공하는 종목(주로 미국 상장 ETF)에서만 나옵니다. 국내(KRX) 상장 ETF는 이 정보가 없는 경우가 많아 "-"로 표시됩니다.
- 시세는 실시간이 아니라 Yahoo Finance가 제공하는 지연 시세입니다.
- **구성종목(보유 종목·비중)**은 각 운용사 사이트의 공개 API에서 가져옵니다. 현재 **KODEX(삼성자산운용)·SOL(신한자산운용)·TIGER(미래에셋자산운용)·KIWOOM/KOSEF(키움투자자산운용)·RISE(KB자산운용, 구 KBSTAR)·ACE(한국투자신탁운용)·PLUS(한화자산운용, 구 ARIRANG)·TIMEFOLIO(타임폴리오자산운용)·KoAct(삼성액티브자산운용)** 브랜드 ETF를 지원하며, 그 외 운용사(HANARO/1Q 등) ETF는 안내 메시지가 표시됩니다. (KRX 정보데이터시스템은 로그인이 필요해 사용할 수 없고, 1Q는 API는 있지만 어떤 종목코드를 넣어도 동일한 목록을 반환해 실제 구성종목 데이터가 아닌 것으로 확인되어 제외했습니다. ACE는 페이지가 보여주는 www 호스트가 아니라 별도 API 서브도메인(papi.aceetf.co.kr)을 쓰고 있었고, PLUS는 API 자체는 www 호스트에 있었지만 날짜(`d`) 쿼리 파라미터가 없으면 조용히 SPA 화면을 대신 돌려줘서 처음엔 못 찾았던 것으로 확인해 재연동했습니다.) 구성종목 목록은 기본적으로 접혀 있고, "구성종목" 영역을 클릭하면 펼쳐지며, 헤더에 종목 수가 표시됩니다. 각 구성종목의 **상장 시장·시가총액·시가총액 순위**는 국내 종목의 경우 Naver 모바일 API의 코스피·코스닥 전 종목 시가총액 순위 데이터를, 미국 종목(TIGER/KODEX 미국S&P500처럼 미국 주식을 직접 담는 ETF의 구성종목)은 Yahoo Finance 스크리너 API로 상위 2,000개 미국 상장 종목 순위를 서버에서 1시간 캐시해 붙입니다(둘 다 첫 조회 시엔 백그라운드로 새로 받아오는 동안 "-"로 보이다가, 몇 초 뒤 재조회하면 채워집니다). 코스피는 빨간색, 코스닥은 파란색, 나스닥·뉴욕증권거래소 등 해외 시장은 별도 색으로 표시됩니다. 현금성 자산 등 실제 상장 종목이 아닌 항목은 "-"로 표시됩니다.
- **공모펀드 구성종목**은 지원하지 않습니다. 한국 공모펀드는 ETF와 달리 일별 구성종목(PDF) 공시 의무가 없어(분기별 자산운용보고서만 발간) KOFIA를 포함해 무료로 제공되는 구조화된 API를 찾지 못했습니다.
- 개인 용도의 로컬 조회 목적으로 만들어졌습니다. Flask 개발 서버(`app.run`)는 프로덕션 배포용이 아닙니다.
